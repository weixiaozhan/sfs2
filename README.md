# 星轨工坊 · Orbit Forge

一款 2D 火箭建造与轨道飞行沙盒游戏：在装配车间用部件拼出火箭，从发射台起飞，
进入轨道，飞向卫星和其他行星，再安全返回。纯 HTML5 Canvas + 原生 JavaScript，无依赖、无构建步骤。

## 运行

直接用浏览器打开 `index.html` 即可（也可以 `python3 -m http.server` 后访问）。

## 玩法

**装配**：从左侧拖出部件放到网格上，相邻部件自动连接；开启「对称」可一次放置左右两枚助推器。
右侧实时显示每一级的推重比与 Δv。上方可载入三枚示例火箭。

**飞行**

| 操作 | 按键 |
| --- | --- |
| 转向 | A / D 或 ← / → |
| 油门 | W / S 或 Shift / Ctrl，Z 满、X 关 |
| 执行下一级 | 空格 |
| 时间加速 | `,` / `.`（`/` 复位） |
| 地图 | M，滚轮缩放，拖动平移 |
| 重飞 / 回装配 | R / Esc |

也可以直接点击箭体上的发动机、分离器、降落伞来单独操作；触屏设备有对应的屏幕按钮。

**入轨要点**：垂直起飞，约 1 km 后缓慢向一侧倾斜；远点升到 40 km 以上后关机滑行，
在远点附近水平加速，直到近点也高于 30 km 大气层。

## 特性

- 真实的二体轨道力学：开普勒传播、引力范围切换、轨迹预测（相遇 / 逃逸 / 撞击）
- 最高 1,000,000× 的在轨时间加速
- 大气阻力、再入、降落伞、着陆腿与耐撞速度
- 自动分级（含捆绑助推器）、燃料按分离器分区、逐级 Δv 估算
- 恒星赫利昂，行星维斯帕、艾瑞亚（母星，卫星塞洛）、鲁布拉
- 11 个里程碑任务，设计与进度保存在浏览器本地

## 测试

```
node test/sim.test.js
```

无界面测试会用自动驾驶把示例火箭送入轨道、离轨并开伞着陆，并验证地月转移的轨迹预测与实际飞行一致。

## 结构

- `js/data.js` 天体、部件、示例火箭、任务
- `js/kepler.js` 轨道数学
- `js/rocket.js` 连接关系、分级、Δv
- `js/sim.js` 飞行物理与轨道传播
- `js/partsdraw.js` 部件绘制
- `js/builder.js` / `js/flight.js` / `js/main.js` 界面
